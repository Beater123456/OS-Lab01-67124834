2. POSIX Permissions

Linux Permission แบ่งสิทธิ์ออกเป็น 3 กลุ่ม คือ

Owner
Group
Others

โดยสิทธิ์แต่ละแบบมีค่าดังนี้

Read    = 4
Write   = 2
Execute = 1

โจทย์กำหนดให้

Owner มี Read, Write และ Execute
= 4 + 2 + 1
= 7

Group มี Read และ Execute
= 4 + 1
= 5

Others ไม่มีสิทธิ์
= 0

ดังนั้น Permission แบบ 3 หลักคือ

750

ถ้าใช้ใน Python จะเขียนได้ว่า

os.chmod(filename, 0o750)

Permission นี้มีความหมายว่า

Owner  = rwx
Group  = r-x
Others = ---

หรือ

rwxr-x---
